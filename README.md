# 📚 Sistema de Gestión de Biblioteca

Este proyecto consiste en una aplicación web desarrollada en Java con Spring Boot para gestionar una biblioteca. Permite administrar libros, autores, editoriales y usuarios de forma sencilla y eficiente.

## 🛠️ Tecnologías utilizadas

- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Hibernate
- RESTful API
- Git & GitHub
- Postman

## 🔍 Funcionalidades principales

- Alta, baja y modificación de libros, autores y editoriales.
- Gestión de usuarios.
- Conexión a base de datos con JPA.
- Endpoints REST para consumir desde frontend.
- Validaciones y manejo de errores.

## 🚧 Estado del proyecto

🔧 En desarrollo.  
Actualmente trabajando en la implementación de control de usuarios.

## 📁 Estructura del proyecto

- `/entidades`: modelos de base de datos.
- `/controladores`: controladores REST.
- `/servicios`: lógica de negocio.
- `/repositorios`: interfaces para persistencia.
